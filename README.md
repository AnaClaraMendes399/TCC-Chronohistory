# Tcc-Chronohistory

> Projeto de TCC — Chronohistory: jogo HTML5 simples e recursos relacionados.

## Descrição

Este repositório contém arquivos do jogo (HTML, CSS, JS) e recursos (imagens, sons) usados no projeto.

## Como executar

- Abrir `index.html` no navegador para testar localmente.
- Ou servir com um servidor HTTP simples:

```bash
python -m http.server 8000
# depois abra http://localhost:8000
```

## Git / Push

O repositório remoto ainda não está configurado aqui. Para enviar (`push`) para o GitHub:

1. Crie um repositório vazio no GitHub (sem README).
2. Configure o `origin`:

```bash
git remote set-url origin https://github.com/SEU_USUARIO/SEU_REPO.git
git push -u origin main
```

Quando você criar o repositório remoto, cole a URL aqui que eu faço o push para você.

## Observações

- Arquivos grandes e binários (áudio/imagens) já estão no repositório local; considere usar `.gitignore` ou LFS se necessário.
